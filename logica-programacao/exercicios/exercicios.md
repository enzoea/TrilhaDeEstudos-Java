# Exercícios de Lógica

10 exercícios misturando tudo que foi visto até agora (variáveis, operadores, entrada/saída, condicionais, repetição, vetores e funções). Tente resolver cada um sozinho antes de olhar o arquivo `.java` correspondente, que traz uma resolução comentada.

Cada exercício tem seu arquivo de resolução com o mesmo número, ex.: exercício 1 → [01-par-ou-impar.java](01-par-ou-impar.java).

## 1. Par ou Ímpar

Leia um número inteiro e diga se ele é par ou ímpar.

```
Entrada: 7
Saida: Impar
```

## 2. Maior de Três

Leia três números inteiros e imprima o maior deles.

```
Entrada: 4, 9, 2
Saida: O maior e 9
```

## 3. Média e Situação

Leia três notas (0 a 10), calcule a média e informe a situação:
- média >= 7: "Aprovado"
- média >= 5: "Recuperacao"
- abaixo de 5: "Reprovado"

```
Entrada: 8.0, 6.0, 7.0
Saida: Media: 7.0 - Situacao: Aprovado
```

## 4. Tabuada

Leia um número inteiro e imprima a tabuada dele, de 1 a 10.

```
Entrada: 5
Saida:
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

## 5. Soma e Média de um Vetor

Leia 5 números, guarde em um vetor (`array`) e calcule a soma e a média deles.

```
Entrada: 10, 20, 30, 40, 50
Saida: Soma: 150.0 - Media: 30.0
```

## 6. Número Primo

Leia um número inteiro e diga se ele é primo ou não. Use uma função `ehPrimo(int numero)` que retorna `boolean`.

```
Entrada: 7
Saida: 7 e primo
```

## 7. Sequência de Fibonacci

Leia um número `N` e imprima os primeiros `N` termos da sequência de Fibonacci (cada termo é a soma dos dois anteriores, começando com 0 e 1).

```
Entrada: 8
Saida: 0, 1, 1, 2, 3, 5, 8, 13
```

## 8. Maior e Menor de um Vetor

Leia 5 números, guarde em um vetor e imprima o maior e o menor valor encontrados.

```
Entrada: 4, 8, 1, 9, 3
Saida: Maior: 9 - Menor: 1
```

## 9. Contador de Vogais

Leia uma palavra e conte quantas vogais (a, e, i, o, u) ela tem, ignorando maiúsculas/minúsculas.

```
Entrada: Programacao
Saida: 5 vogal(is)
```

## 10. Calculadora com Funções

Crie uma calculadora que leia dois números e uma opção (1-soma, 2-subtracao, 3-multiplicacao, 4-divisao), e use uma função separada para cada operação para calcular e imprimir o resultado.

```
Entrada: 10, 3, opcao 4
Saida: Resultado: 3.3333333333333335
```
